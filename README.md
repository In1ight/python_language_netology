# Игра «Жизнь»

Домашнее задание №1.

## Запуск

```bash
python3 life.py
```

## Команды

- `c строка столбец` — изменить состояние клетки; координаты от 0 до 9;
- `r доля` — случайно заполнить поле, например `r 0.2`;
- `n` — выполнить один шаг;
- `8` — один раз показать количество соседей у каждой клетки;
- `?` — показать справку;
- `q` — выйти.

Также вместо латинской `c` можно вводить русскую `с`.
